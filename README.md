# WatchGuard Firebox Lab

Hands-on lab built around a physical WatchGuard Firebox T25.

The lab covers:

- VLAN segmentation
- Firewall policies
- DHCP
- Management isolation
- Guest isolation
- HTTPS inspection
- SSL VPN
- IKEv2
- Certificates
- Fireware CLI
- Troubleshooting
