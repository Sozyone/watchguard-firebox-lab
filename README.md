# WatchGuard Firebox Lab

Lab using a physical WatchGuard Firebox T25.

Covers:

- VLANs
- Firewall rules
- DHCP
- Management and guest isolation
- HTTPS inspection
- SSL VPN
- IKEv2
- Certificates
- Fireware CLI
- Routing
- Troubleshooting
- PowerShell testing
